# Manutenção do PilaManager

Aplicação atual: Next.js, React, Node.js e PostgreSQL no Railway.

- Leia o README e os arquivos de docs antes de alterar o projeto.
- Altere apenas o que foi solicitado e preserve as funcionalidades e o visual.
- Use dados fictícios nos testes e na demonstração.
- Não inclua senhas, tokens, arquivos .env, chaves ou backups no Git.
- Confirme sessão e permissões no servidor para operações protegidas.
- O PostgreSQL é a referência dos dados; o navegador mantém apenas cópias de uso e preferências.
- As atualizações do banco ficam em postgres. Não altere arquivos SQL já aplicados; crie uma nova atualização.
- Reaproveite as regras existentes e evite duplicação ou dependências sem uso.
- Execute testes, verificação de tipos e build nas mudanças de código.
- Confira os links em mudanças de documentação.
- Não afirme que uma operação funciona sem verificar o resultado.
